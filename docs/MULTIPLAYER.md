# 联机指南（局域网 / 虚拟局域网 / 内网穿透 / 独立服务器）

卫戍协议：盟约 的联机拓扑很简单：**一端跑游戏服务器，所有人用浏览器或 App 连它**。
服务器内嵌在安卓 App 里（本机开服），也可以跑在任意一台 Node 22+ 的电脑上。
本文覆盖四种从"同 Wi-Fi"到"跨互联网"的玩法。

## 0. 三种进入方式

| 方式 | 谁 | 怎么做 |
|---|---|---|
| 单人游玩 | 一个人 | 启动 App → 开始游戏（本机开服），离线可玩 |
| 开房做房主 | 房主 | 同上；把房主屏幕上的地址给朋友 |
| 去加朋友 | 客机 | App「加入对局」自动搜索；搜不到就手动输地址 |

客机**不需要装 App**：任何现代浏览器打开房主地址即可加入（UI、操作、语音全在网页里）。

## 1. 同一 Wi-Fi（默认）

- 房主开服后，屏幕显示 `http://<房主局域网IP>:3000`；
- 朋友浏览器直接打开该地址，或用 App 的「加入对局」——同一网络里会自动列出房主（mDNS/NSD 发现）。

## 2. 虚拟局域网（异地组网）

UU 加速器、Tailscale、ZeroTier 等把两台设备拉进同一个虚拟网段后，用法与第 1 步完全相同：
房主把**虚拟网段内的 IP** 给朋友（Tailscale 是 `100.x.x.x`），朋友手动输入 `IP:3000` 加入。
App 的加入框支持任意 IP / 域名 + 端口。

## 3. 内网穿透（frp / easyfrp）

没有公网 IP、也不想装组网软件时，用穿透：**一台有公网的中转机把房主端口暴露出去**。

### 3.1 easyfrp（推荐，本仓库适配的方案）—— 从注册到开服全流程

easyfrp 是面板化的 frp：网页控制台管理隧道，客户端只有一个 `easyfrpc.exe` + 一行控制地址。

**第 1 步 · 注册与套餐**：打开 `https://easyfrp.sian.one/` → 右上角「控制台」→ 注册账号 → 「套餐」购买（本游戏每客户端流量仅几 KB/s，最小套餐足够）。

**第 2 步 · 先创建"客户端"**（顺序关键——隧道必须绑定一个客户端，否则运行时报"配置格式错误"）：控制台 →「客户端」页 → 新建，随便命名（如 `stronghold`）。创建后该条目会给出**控制地址**（形如 `wss://easyfrp.sian.one/<uuid>`），把它写进电脑上 `easyfrpc.exe` 同目录的 `config.txt`：
```
control wss://easyfrp.sian.one/<你的客户端uuid>
```

**第 3 步 · 再创建隧道**：控制台 →「隧道」页 → 新建，按表单填：
| 表单项 | 填什么 |
|---|---|
| 套餐 / 传输配置 / 节点 | 选你买的套餐，节点任选（延迟差异见下文自测） |
| 客户端 | **选第 2 步创建的客户端**（必选！） |
| 通信协议 | `TCP` |
| 连接池 | 默认 0 即可 |
| 隧道名称 | 任意（如 `stronghold`） |
| 内网 IP | **房主手机的局域网 IP**（App 开服后屏幕显示，例 `192.168.3.85`） |
| 内网端口 | `3001`（以 App 屏幕显示为准；ColorOS 占 3000 时 App 自动换端口） |
| 隧道类型 | `tcp` |

**第 4 步 · 运行客户端**：电脑上启动 `easyfrpc.exe`——它会连上控制地址并自动拉取第 3 步的隧道配置（面板改配置实时生效，无需重启客户端）。日志出现隧道信息、不再报错即成功（"配置格式错误"几乎都是隧道没绑客户端或内网 IP/端口填错，回控制台核对）。

**第 5 步 · 开服与联机**：手机 App 正常开服 → 朋友（任何网络）浏览器或 App「加入对局」手动输入 `面板IP:远程端口`。延迟 ≈ 本地到节点的 RTT（实测该节点 ~95ms，回合制可玩）。

**延迟自测**：电脑上 `ping <面板IP>` 看基础 RTT；开服后 `curl -o NUL -s -w "tcp=%{time_connect}s ttfb=%{time_starttransfer}s
" http://<面板IP>:<远程端口>/healthz` 量穿透链路的真实开服响应。

### 3.2 自建 frp

中转机（有公网 IP）跑 frps，房主侧跑 frpc：

```ini
# frpc.ini（房主侧，指向手机）
[common]
server_addr = <中转机公网IP>
server_port = 7000

[stronghold]
type = tcp
local_ip = 192.168.3.85
local_port = 3000
remote_port = 13000
```

朋友填 `<中转机公网IP>:13000`。

### 3.3 其他

ngrok / Cloudflare Tunnel / 花生壳等同理：把手机 `3000` 端口暴露出去即可，
App 端把分配的 `域名:端口` 填进加入框（支持域名 + https）。

## 4. 独立服务器（电脑常驻开房）

不用手机开服，用一台电脑做常驻服务器（性能更好、不怕切后台）：

```bash
# Node.js ≥ 22
git clone <本仓库> && cd Stronghold-Protocol-Android
npm ci            # 首次；同时下载游戏资产（~280 MB，可断点续传）
npm start         # 等价 node server/index.js，PORT/HOST 走环境变量
# 或：node scripts/launch.mjs --port 3000 --host 0.0.0.0 --no-open
```

- 局域网朋友连 `http://<电脑IP>:3000`；再配合 §3 穿透即可跨网；
- `docs/DEPLOY.md` 有部署细节（Docker、systemd、资产离线包）；
- 安卓 App 客机连独立服务器：「加入对局」→ 手动输入服务器地址。

## 5. 端口与防火墙备忘

| 端口 | 用途 |
|---|---|
| 3000（或 App 内回退 3001+） | HTTP + WebSocket 游戏服务 |
| 5353 / mDNS | App 局域网自动发现（ColorOS 设备可能占用 3000，App 会自动换端口，以屏幕显示为准） |

穿透/组网时只需暴露游戏端口；发现协议不出局域网，跨网一律手动输入。
